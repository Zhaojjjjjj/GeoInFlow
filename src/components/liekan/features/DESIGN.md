# Liekan AI 页面设计

## 1. 视觉主题
沿用已批准的 AI 原型。安静的白色工作区配蓝色操作，配置以状态和参数为中心，对话以网站和生成依据为中心。

## 2. 色彩角色
正文 #16181d，次级文字 #697386，提示 #9aa3b2，分隔线 #e9ecf1，浅底 #f5f7fa，主操作 #0f62fe，选中 #edf2ff，成功 #0e9f6e，错误 #d52f42。

## 3. 字体
继承产品 Inter、系统中文字体，正文 13px、1.75 行高，辅助信息 11.5px，页面标题 22px、600，数字使用等宽数字。中文标题保持正常字距。

## 4. 组件
控件圆角 9px，面板 14px，输入问题区域 16px。禁用动作说明实际权限和状态。指针按压缩放 0.96，键盘操作无动画，焦点为 2px 蓝色轮廓。

## 5. 布局
工作区自然占满可用宽度，对话宽度上限 860px，配置列表宽度上限 1264px。配置表单与说明使用主次两列，阶段与结果使用主次两列。间距采用 8、12、16、20、24、32px。

## 6. 层次
列表与说明使用边框、浅色底区分。输入区域使用原型轻阴影。测试弹层居中，宽度上限 1080px，背景遮罩表达模态层级。

## 7. 实施规则
保留原统计页面。供应商参数读取真实目录。密钥只在临时密码输入中存在。预览标记尚未校验。最终回答使用服务端已提交结果。历史依据读取生成时快照。模型文本只按纯文本渲染。提交附近标明供应商、模型、应用上下文窗口及来源，说明外发脱敏汇总、有限样本、本次问题与最多 6 轮历史，并提示避免输入凭据或个人资料。本地指引标明 0 次供应商调用。窗口优先使用服务端连接字段，自定义或未匹配参数采用 16,384 Token 保守估算。测试按配置检查、发送请求、首次文本、接收完成展示，事件记录仅在页面内存保留受控阶段与时间，上限 64 条。供应商响应只展示安全状态码与请求标识，缺值显示未知。

## 8. 响应式
650px 以下改为单列，供应商选择保留两列，弹层距离屏幕边缘 12px，列表允许自身横向滚动。所有常用操作保持至少 40px 点击高度。

## 9. 后续组件指引
配置控件使用白底、#e9ecf1 边框、9px 圆角、13px 正文。依据说明使用 #f5f7fa 底、14px 圆角、11.5px 辅助文字、1.75 行高。测试弹层使用 1080px 上限、16px 圆角、22px 内边距。新增动作使用 #0f62fe 主色和 2px 焦点轮廓。

## 10. 对话阅读与续问
2026-10-05 用户要求全面优化对话、续问和加载体验。对话沿用 agent.html 首页的 860px 阅读宽度、白色底、16px 输入框和 #0f62fe 操作。用户问题使用浅底气泡，回答直接展开在白色阅读区。续问框默认一行，随输入增长至 180px，底部可见；输入框内的选择器保持单层边界。加载展示真实阶段、实际等待秒数和待核验摘要，原始 JSON 与模型推理过程不进入阅读区。失败事件立即回查已持久化任务，回查不创建供应商调用。运行指标、调用说明和限制可展开查看，回答支持复制。向上阅读时停止自动跟随。沿用 CSS Modules、Inter 和系统中文字体，动画仅用于加载指示并尊重减少动画设置。
