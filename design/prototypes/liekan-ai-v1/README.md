# 猎看统计 AI 能力交互原型

全局管理侧栏的“快速发起”位于“数据总览”上方。“AI 能力”分类保留“AI配置器”。本原型用于确认页面与流程，所有连接测试、数字、日志和回答均为演示。

## 页面与状态

- `ai-chat.html`：快速发起、未配置引导、分析首页、对话示例、相关数据入口。
- `ai-config.html`：默认 API 列表，包含模型、接口、密钥状态、连通情况、最近测试及操作。
- 列表右上角“新建 API”提供七家官方模型模板与自定义模板。选择模型自动填写通用配置，补充 Key 即可保存；高级配置可调整名称、协议、模型、接口与空间。
- “实时测试”打开居中宽屏弹窗，展示检查进度、请求摘要、流式回答、耗时及事件。支持正常、Key 无效与超时预览，关闭或重测取消旧任务。
- [主流模型 API 接入指南](model-api-guide.md)包含官方来源、地域说明、协议与排查提示；页面内也提供接入指南。
- 顶部“预览状态”可以切换未配置、就绪、示例对话、无数据、数据不足、服务失败、成员权限。
- 查询参数 `scene`、`site`、`period` 控制预览状态与范围；`view` 展示回答关联的后台入口。
- 演示站包含最近 7 天及前期对照；最近 30 天展示覆盖不足。官网处于未接入状态。

启动本地预览，访问 `/liekan-ai-v1/ai-chat.html`：

```sh
python3 -m http.server 3005 --bind 127.0.0.1 --directory design/prototypes
```

## 视觉与交互约定

视觉依据为用户图二和本地 `geo-workbench/v3/agent.html`，字体、品牌资源沿用 `liekan-ui-v1`。使用独立普通 CSS，不修改已冻结的视觉参考与生产导航配置。

- 白色画布、228px 侧栏、60px 顶栏、860px 对话容器。
- 主色 #0F62FE，主文字 #16181D，辅助文字 #697386，分隔 #E9ECF1，选中 #EDF2FF。
- Inter 与系统中文字体；标题 30px，正文 13px，输入 14px；控件 9px、面板 14px、输入容器 16px 圆角。
- 宽输入框为首页主操作，常用功能为三列入口；回答按范围、结论、依据、建议、后台跳转组织。
- 按压反馈，键盘焦点、跳到正文、移动导航关闭与焦点返回；减少动态偏好关闭变换。
- 900px 以下侧栏收为菜单，650px 以下配置单列，表格在自身容器内滚动。

## 正式接入边界

原型不请求模型 API、生产接口或数据库。密钥不写入浏览器存储。当前标签页保留连接的非敏感元数据与演示测试状态；保存时清空输入的 Key。查询参数可恢复预览场景。API 列表支持编辑、默认模型、启停与删除确认；成员预览禁用配置和测试操作。

正式实现应通过 Liekan 服务端契约读取授权网站数据，并安全保存 API 密钥；在用户确认发送范围后向所选模型发送统计摘要及必要脱敏记录。模型回答中的数值与链接应由服务端事实核验，页面入口必须携带明确网站标识与合法时间范围。

原型回答区分观测事实、待验证原因和建议。空数据、覆盖不足、服务失败各自有恢复入口；品牌提及率、回答排名与引用率需要额外 AI 回答监测数据。

现有生产代码、数据库结构和视觉参考保持原有状态，本原型尚未接入真实分析。
