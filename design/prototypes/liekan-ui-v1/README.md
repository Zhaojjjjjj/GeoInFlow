# 猎看统计 UI 原型合集 v1

本轮交付为可浏览、可操作的 UI 设计，等待确认后再融合后端。以已确认的 geo-stats-v3 为视觉基准，包含 **68 个补充页面与流程、11 个原有参照页、60 条上游路由的对应清单**。

## 浏览

预览入口：[打开页面合集](http://localhost:3003/index.html)。

页面合集可搜索、按功能分组浏览，并提供“60 条路由覆盖”和“设计与口径说明”。推荐从“添加网站 → 身份与安全 → 配置漏斗 → 会话详情 → 看板编排”开始。原有参照页在新标签页打开。

| 分组 | 补充页面数 | 主要范围 |
| --- | ---: | --- |
| 网站与接入 | 6 | 创建网站、三步向导、跟踪代码、安装验证、设置、行为采集 |
| 身份与安全 | 9 | 登录、2FA 登录、绑定与恢复码、账户、API Key、偏好、SSO 状态 |
| 目标与漏斗 | 4 | 目标和漏斗列表、定义表单、事件属性条件及步骤排序 |
| 访客与事件 | 5 | 实时访客、事件列表与属性、会话列表与时间线 |
| 筛选与人群 | 8 | 条件组件、分群、行为队列、留存矩阵、旅程与路径详情 |
| 高级分析 | 5 | 五种 UTM 字段、首末触归因、多维拆分、期间对比、图表注释 |
| 协作与管理 | 16 | 团队、角色、后台、工作台、看板编排和只读分享 |
| 扩展能力 | 12 | 性能、收入、热力图、回放、链接、像素和完整导出 |
| 边界状态 | 3 | 权限不足、登录过期、页面不存在 |

## 操作方式

- 登录原型使用 `admin / liekan`，可勾选双重验证；演示验证码为 `123456`，演示恢复码为 `DEMO-01`。
- 接入向导可创建示例网站、选择安装方式并模拟接收首条访问。
- 漏斗可添加二至八步、修改窗口、排序步骤并加入事件属性条件。保存后显示配置摘要。
- 分群、队列和目标提供必填与条件校验。修改表单时增加条件会保留草稿。
- 表格支持本页检索与表头排序。访客与事件入口可以进入明细，留存格子可以查看分子和分母。
- 看板支持添加、删除、调整次序和全宽/半宽。工作台固定的网站支持排序。
- API Key 创建后完整示例值展示一次，列表仅显示掩码。恢复码、密钥、访问码均为无效演示值。
- 分享配置与公开预览使用同一份内存状态，关闭当前分享后显示关闭状态。内部管理页面保持独立。
- 热力图使用内置示例网页。回放播放器展示合成页面，可播放、暂停、定位和保存示例录制。
- 导出可生成 ZIP、CSV 或 JSON 示例文件，下载名及清单包含 demo 标记，不包含生产数据。
- 评审工具栏可切换正常、无数据、加载、失败和无权限状态，以及所有者、成员、只读角色。角色切换用于确认界面；正式权限由后端验证。
- “重置示例”或刷新页面会恢复初始状态。导航保留当前标签页的内存状态，在新标签页打开会使用初始示例。

## 本轮边界

原型目录独立于生产源码，不调用实际 API、数据库或 tracker。跟踪代码以文本显示，示例域名不用于实际安装。

原有 60 条路由包含别名、重定向和拦截弹层。`manifest.json` 与 `assets/route-map.js` 给出全部对应关系，生产路由保持原样。原有十一页的参考副本仅替换字体、Tailwind 和 ECharts 外部资源地址，原始参考文件保持原样。

页面中的汇总、趋势、矩阵与明细使用固定示例数据。日期范围和筛选用于演示控制，真实查询、统计口径、采集与任务执行在后端融合时验证。多语言和深色主题保留设置选项，本轮视觉稿覆盖简体中文浅色。

新增功能的侧栏分组、页面标签、接入步骤和扩展能力字段属于本轮待确认设计。确认重点为布局、字段、交互、图表形式、状态表达及页面归属。

当前运行的 Docker 系统继续使用 Liekan 0.1.2，地址为 http://localhost:3002。原型使用独立端口 3003，本轮不构建生产镜像或合并主分支。

## 本地启动

从 Liekan 仓库目录执行：

```sh
python3 -m http.server 3003 --bind 127.0.0.1 --directory design/prototypes/liekan-ui-v1
```

只将原型目录作为静态服务根目录。页面需要通过 HTTP 打开，以加载本地模块。所有图表、字体与参考资源均已放入合集，浏览时不需要外部 CDN。

## 结构与授权

- `index.html`：原型合集入口。
- 各功能 `.html`：可直接访问的页面入口。
- `assets/`：共用样式、示例状态、渲染与交互、ECharts 和字体。
- `reference/`：十一页视觉参照副本。
- `manifest.json`：页面与上游路由对应清单。
- `DESIGN.md`：视觉、布局、响应式与组件规范。
- `LICENSE`：项目 MIT 授权，保留 Umami 与 Liekan 版权。
- `licenses/`：Inter 字体、ECharts 图表和 Tailwind 3.4.17 的第三方授权文件。
