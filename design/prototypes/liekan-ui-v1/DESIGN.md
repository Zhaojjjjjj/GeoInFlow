# 猎看统计补充 UI 原型规范

## 1. 视觉主题
继承 geo-stats-v3 的紧凑分析界面。原有十一页作为锁定参照，新页面服务于网站接入、配置、明细和管理。

## 2. 颜色与角色
主文字 #16181D，辅助文字 #697386，淡文字 #9AA3B2，分隔 #E9ECF1，画布 #F5F7FA，白色侧栏及内容面板。主操作 #0F62FE，第二序列 #4589FF，选中 #EDF2FF。绿色 #0E9F6E 表示成功，红色 #F04452 表示错误。统计增减沿用原型语义，增幅红色，降幅绿色，同时用文字表达方向。

## 3. 字体
本地 Inter 400/500/600/700/800，中文使用 PingFang SC、Microsoft YaHei 和系统回退。页标题 16px/700，面板标题 14px/700，正文 13px/400，表格 12.5px，说明 11.5px，指标 24px/700。正文行高 1.5，导航图标 16px、描边 2px。数字采用等宽数字特性，数值列右对齐，主要指标沿用品牌蓝。

## 4. 组件
面板圆角 14px、边框 1px #E9ECF1；按钮、输入与导航圆角 9px；状态标签圆角 6px；品牌标识圆角 10px。操作按钮有按压反馈，禁用按钮同时提供原因。管理编辑沿用右侧 560px 抽屉，复杂漏斗与看板使用完整配置页。所有图表沿用 ECharts 5.5.0 的轴线、图例和配色。

下拉框使用统一 16px 倒三角图标，图标右侧距边框 12px，文字区右内边距 38px；评审工具栏、表单及弹层采用同一规则。桌面按钮最小高度 35px，900px 以下的按钮、导航与标签最小高度 40px。多选框与系统高对比度模式保留原生控件。

## 5. 布局
桌面侧栏 228px，内容最大宽度 1200px，左右 32px，顶部 24px，顶栏 60px。间距使用 4/8/12/16/24/32px。摘要先于趋势，趋势先于明细。表单显示必填标识、字段说明和相邻错误信息。两至四列表格按列数设置最小宽度，保证桌面半宽面板完整展示数值；移动端在表格自身容器内滚动。

## 6. 层次
沿用白底、浅灰画布和细边框，品牌阴影沿用原型。抽屉与弹层使用轻阴影。图表面板不增加装饰背景。

## 7. 项目约束
原始 design/reference/geo-stats-v3 文件保持原样。合集内 reference 副本仅替换外部资源地址以支持本地浏览。示例数据与未接入说明持续可见。角色、空、加载、错误状态可在评审工具栏切换。全部修改仅在当前浏览器内存中生效。原型页面不调用生产接口，跟踪脚本以文本展示。MIT 保留上游版权，第三方字体与图表授权单独保留。

## 8. 响应式与无障碍
900px 以下侧栏进入可关闭的抽屉。540px 以下表单单列，摘要两列，表格在自身容器横向滚动，页面主体不横向溢出。触控按钮最小 40px，提供可见键盘焦点、跳到内容入口、弹层焦点管理及 reduced-motion。新增页面使用简体中文；主题设置保留上游选项，本轮视觉稿覆盖浅色。

## 9. 后续设计提示
- 新建配置抽屉：白底 560px 宽、24px 内边距、14px/700 标题，输入 9px 圆角和 #E9ECF1 边框，主按钮 #0F62FE，说明 11.5px #697386。
- 新建分析页：228px 白色侧栏、#F5F7FA 画布、1200px 内容上限及 32px 横向间距，14px 白色面板，标题 16px/700 #16181D。
- 新建趋势图：使用 #0F62FE 与 #4589FF 序列、1px #E9ECF1 实线网格，数值轴 10–10.5px #9AA3B2，横向条形图类别轴 11px #697386。折线宽 2.5px、平滑且不显示点标记，图例放在顶部靠右，图表高度 280px，数字列右对齐。性能与收入提示保留单位，图例交互提示仅用于有图例的图表。
