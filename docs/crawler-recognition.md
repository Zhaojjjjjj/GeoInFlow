# 蜘蛛识别与规则兼容

身份目录维护稳定 ID、名称、厂商、用途与能力。HTTP 识别、官方范围核验、来源归因、robots 草稿和远端控制分别声明能力。名称表示请求声明的身份，核验状态单独展示。内置初始目录启用 60 个 HTTP 请求标记和 1 个签名身份，PetalBot 保持待复核，3 个 robots 用途控制项单独登记。管理员发布的目录为运行时依据，页面显示实际版本与数量。Cloudflare 与 Nginx 控制仍限定原有 13 项。

## 网站规则

新站点及未改动的历史默认规则使用 `official` 模式，使用当前已发布目录。软件升级带来的变化先进入审核草稿。网站可保存停用 ID、分类覆盖与自定义规则。分类覆盖保留官方身份及 AI 请求资格。自定义名称与官方名称相同时仍使用独立未映射身份。

蜘蛛明细表、内容偏好列表与 CSV 在名称信息中标注“官方身份”或“自定义／历史未映射”，便于区分同名记录。身份标注表示目录映射，来源核验结论仍独立展示。缺少身份字段的旧版响应保留原展示格式。

页面排行保留主力蜘蛛的身份，估算抓取路径仅串联选中身份的记录。近期日志从采集时证据读取身份；缺失历史证据保持未映射，同名记录不据此获得官方身份。

显式空数组迁移为 `disabled`。改名、改序、删除或添加过的旧规则迁移为 `legacy`，保留原顺序与子串行为。迁移前内容保存在 `rules_migration_snapshot`。只修改 robots、白名单或展示偏好保持原规则模式。

编辑器默认保留网站规则模式。转换预览将完整名称、厂商和匹配词相符的旧条目映射为官方 ID，保留类型覆盖，其余条目保留为自定义规则及原匹配方式；未配置的官方条目保持停用。旧版顺序与包含匹配在转换后可能变化，用户核对预览后确认转换草稿，再保存生效。

新配置写入携带 `expectedRulesRevision`，并发旧版本返回 409。从旧模式转入官方模式需要转换预览后的 `conversionConfirmed`。新提交的旧格式规则补充明确匹配方式，无法通过四字段官方同名记录获得历史官方身份。迁移读取继续兼容真正的历史四字段记录。编辑旧规则时，在当前站点已存档且内容未改变的历史条目保留原身份；新增和修改的条目使用明确匹配模式。

## robots 与能力说明

robots 草稿仅使用厂商资料已确认的 token。观察目录、待复核条目不生成 robots 草稿或诊断判定；Bytespider 保留既有 Cloudflare/Nginx 控制能力。缺少 robots token 不影响 HTTP 识别。帮助目录分别显示资料收录、本版本识别能力、可核验范围、网站启用状态与范围健康；全局帮助页没有网站上下文时明确显示未选择与未读取。

解析、访问诊断和草稿合并共用 token 校验：RFC 9309 产品标记规则之外，仅兼容已启用目录中经过复核的完整 token（如 AI2Bot、360Spider、MJ12bot 和搜狗标记）。比较忽略大小写，内部空格保持精确匹配；拒绝任意带数字或空格的未收录标记以及控制字符。

## 事件与版本

规则版本包含匹配器版本、目录版本、顺序、名称、有效身份、模式、分类与 AI 资格，以及包含签名身份启停和分类覆盖的完整网站配置。规则档案保留原 rules 数组，并在 crawler_configuration 中记录配置。档案按网站隔离。接收与配置更新使用同一网站锁，排队记录保存接收时分类，处理时不重新套用当前规则。事件标识和批次去重独立于分类版本。

日志的 AI 资格、识别状态、候选 ID、核验版本和观测时间均可为空，以支持旧日志及旧排队数据。缺少的历史证据保持未知。内置公开范围使用内容摘要版本，避免将核验通过与版本未记录混在一起。历史分类和核验结果不自动重写。

## 升级与兼容运行

迁移为追加式，已执行 SQL 不得修改。迁移登记摘要与发布迁移数量同步维护。部署前在隔离数据库验证迁移、重复运行、并发配置和重复导入。

兼容候选能够读取已登记的后续身份；详情目录附加实际观测身份。风险重算只修正候选版本支持的身份，保留其他身份的风险窗口与状态。日志 worker 的 `--pause-crawler-maintenance` 参数暂停范围刷新与风险分析的领取和发送，日志处理继续运行，已排队维护任务保留。协调应用与 worker 使用同一候选版本，恢复前移除此参数。

回滚保留已执行迁移和新增数据。仅使用完成新 ID、证据字段与排队任务演练的兼容候选；不能将直接重启 0.2.4 作为经过验证的无损回滚。公开范围快照无法补出历史脱敏 IP 已丢失的核验事实。

## 隔离验证

集成用例由 `LIEKAN_CRAWLER_TEST=1` 显式启用，严格要求本机端口 15440、数据库 `liekan_crawler_acceptance`。用例仅清理自身随机网站及事务内夹具，禁止对业务数据库执行重置。

## 官方范围与观测时间

内置初始目录配置 24 个经过复核的 HTTPS 来源，绑定 34 个 HTTP 名称，具体名单见 [蜘蛛目录](crawler-directory.md)。Claude 共享范围绑定三种 Claude 身份，Google common 范围绑定其明确适用的九个 HTTP 名称。AhrefsBot 的范围不用于 AhrefsSiteAudit，Mistral 用户与索引范围不用于训练条目。Amazon 三个官方范围分别绑定训练、搜索和用户触发身份；Kimi 三个来源各自绑定对应身份，HySpider 来源仅绑定混元训练身份。

内容摘要绑定来源、解析器、名称、稳定 ID 与规范化 CIDR。相同内容刷新沿用摘要，成功观测时间独立推进；304 需要已有合格缓存。每条日志保留核验时的版本及观测时间，后续更新不改写该证据。处理时间与事件时间分别使用七天窗口；未来观测时间、无效记录和缺失历史均不能获得新鲜证据。

范围快照与成功观测追加保存，当前指针、待复核候选和来源运行状态单独记录。更新失败保留旧快照及最后成功时间。超过旧条目数 50% 的增删变化，或任一地址族覆盖地址数超过四倍，进入待复核候选。新来源需要随审核版本提供初始基准。Kagi 使用人工审核的范围和实际观测时间，维护进程不会通过重复读取文档刷新其成功时间。旧公共范围与已被日志引用的版本保留，不随当前指针切换删除。

抓取仅由维护进程进行，固定地址拒绝重定向，整体请求和响应体预算 15 秒，响应最多 1 MiB、原始范围最多 5000 条。空列表、错误 JSON、HTML 错误页、非法 CIDR、非公网及全地址范围拒绝激活。数据库外抓取、短事务提交，持久租约与代次保护旧任务结果；全局最多两个来源并发。

浏览器流量质量保留原六个已审核来源绑定及独立可信入口策略。新目录和新增范围不会扩大该信任策略。公开采集 payload 自报 IP 或身份不能建立可信来源。

## 持续维护入口

管理员在全局“爬虫管理”的“来源与核验”页签查看来源维护，包括内容版本、人工复核日期、最后尝试、最后成功、连续失败、下一次检查和待复核状态。IP 更新每小时运行，连续失败三次或 24 小时没有成功观测时告警，七天后证据过期。资料每七天检查，连续失败两次或 14 天未成功时告警。人工复核超过 45 天独立提示维护；自动抓取不会修改人工复核日期。

每周资料检查保存主体摘要与状态，变化形成复核待办。维护者每月对照官方资料审核名称、用途、停用及来源迁移，通过唯一管理页审核草稿、基准和匹配样例，再发布目录版本。新增协议或解析格式仍需代码审核和应用发布。仅凭网页内容变化不能直接更新识别规则，也不发送外部消息。

维护者可运行 `pnpm liekan:crawlers:check-sources` 进行只读来源检查。该命令与维护进程共用来源检查器，不写数据库或运行规则。网络检查与确定性构建、单元测试分开执行；来源不可访问时报告实际错误。无需新增常驻服务、环境变量或外部账户。

全局管理页“待核实与变更”内可按需查询有权限网站的未知名称候选。查询最近七天已有未知请求，最多扫描 100000 条、五秒预算、展示 100 个候选；达到行数、时间或 10000 个不同 token 的处理预算时，显示已完成的部分样本及实际扫描时间。数据库查询未取得记录即超时，显示本次查询未完成。输出只含脱敏后的产品 token、次数与首次、末次时间，完整 UA、IP、路径不会出现在候选响应中。候选不自动获得厂商、AI 资格或可信身份。

帮助中心分别显示资料收录、本版识别、配置的核验范围和当前网站启用状态。站点信息只在完整登录且有网站读取权限的上下文查询；全局来源健康仅系统管理员可查。分享身份、未完成双重验证及公共采集身份不能读取这些维护接口。

## 恢复与验收

范围恢复使用 `restoreRangeSnapshot` 的受控维护调用，只允许同一来源、同一适用映射、已存在成功观测的合格历史版本。恢复沿用该版本已有的成功观测时间，过期版本继续显示过期；未通过的候选不能成为回滚目标。恢复操作会使正在运行的旧任务失效。

本次兼容回退基线采用阶段 B `c9765a540`，应用与 worker 同步切换并使用 `--pause-crawler-maintenance` 暂停范围和风险维护；该候选不领取后续版本新增的资料检查队列。阶段 A 仍按展示类型汇总 AI 请求，会将新版的 Google-InspectionTool 计入 AI，因此不列为本次回退目标。旧数据库表保留当前范围镜像，后续身份、排队批次和可选证据字段由兼容候选读取。迁移继续保留，禁止用旧备份覆盖切换后新接收的数据。恢复到当前版本后取消暂停并检查来源状态。

验收覆盖固定来源解析、304、异常变化阈值、失败恢复、历史版本、并发与过期任务、未知候选隐私与预算、完整会话权限、目录和生成一致性。完整发布门禁另行执行生产构建、Docker 迁移、API、隔离恢复、负载和中英文视觉检查；官方在线检查的失败与本地确定性测试分别报告。

统计证据、采集对账、观察保留期与风险工作流详见 [流量证据与统计口径](traffic-evidence.md)。

## 统一目录发布与页面读取

`/crawlers/manage` 是唯一编辑入口，提供爬虫库、平台与引荐、来源与核验、待核实与变更四个页签。普通完整会话可读取安全的已发布目录；全局维护、草稿、历史和来源健康需平台管理员权限。网站启停和自定义规则继续检查对应网站管理权限。分享身份和未完成双重验证的身份不能访问管理接口。

管理员可直接点击“新增爬虫身份”等新增入口：当前查看发布目录时自动建立草稿并打开表单；已选中草稿时直接在该草稿内新增。保存后仍需核对预览并确认发布。请求结果未确认时可重试同一操作，避免重复创建草稿。

用途与产品形态独立保存。AI 训练、AI 搜索、用户触发、AI 工作台、个人 Agent 是业务筛选，存在交集，不能将五类结果相加。总量按唯一请求计算。平台、产品与身份分别建档，待核实产品保留资料和原因。引荐主机、别名和范围随目录发布；混合搜索平台没有可比较的爬虫分母时不生成 AI 抓取到访比率。

AI 爬虫台账和抓取页面均提供 AI 工作台、个人 Agent 筛选。产品形态以请求记录绑定的历史目录版本为准，缺少身份或历史目录的请求保持未知；当前目录修改不回填历史。形态筛选在聚合和分页前应用，抓取页面的卡片、排行、目录分布与盲区使用同一筛选结果，导出保留相同条件。台账的类型列同时展示用途分类和已登记产品形态，类型构成图继续按用途分类，避免交叉类别重复计算。

两页的筛选顺序统一为全部、AI 训练、AI 搜索、用户触发、传统搜索、AI 工作台、个人 Agent、其他爬虫。“其他爬虫”使用独立条件 `botCategory=other`，纳入已识别爬虫中同时不属于四种已命名用途、且历史产品形态不属于工作台或个人 Agent 的请求。未识别和歧义请求仍在未知请求日志中查看。该条件在统计聚合前应用，覆盖前期对比、抓取页面卡片、具体身份选项、分页和导出；旧的“其他已知”页面链接按新条件恢复。抓取页面继续仅统计具备 AI 统计资格的请求。用途和形态两个维度保留交集，类型构成图中的“其他用途”仅表示用途维度。

发布先校验草稿和正反例，再确认差异，事务切换当前指针。稳定 ID 和已引用条目保留，停用后历史可读。回滚建立新草稿，经预览确认后产生新版本。软件升级对上次种子、管理员当前内容和新种子做三方合并，冲突留给审核，不覆盖管理员修改。

后台同样要求预览同时包含正例和反例。普通草稿基线落后时，重新生成预览会合并原基线、草稿和最新发布内容，并增加草稿修订；同字段冲突保留在草稿中，核对并保存解决结果后才能发布。软件升级候选保留种子采纳记录。回滚草稿基线落后时需重新创建；回滚中的历史名称冲突会保留为可编辑草稿，后续新增记录继续留存。

每次采集、页面读取、分页、导出、AI 分析和风险任务绑定完整不可变目录。页面刷新开始新的读取轮次；导出带页面版本，后台任务提交前检查目录、日志代次和租约。旧排队记录沿用接收时分类，历史缺少版本时保留未知。目录查询暂时不可用时使用已验证的完整快照或内置初始版本；本次使用的版本进入证据。管理写入失败不会发布部分配置。

官方范围与文档抓取仅使用已审核发布的来源。网络请求要求 HTTPS、公网解析结果和固定端口，连接绑定已校验地址，拒绝重定向、URL 凭证和私网，保持时间、体积与并发预算。文档内容、签名代理名称和用户上传内容均不能改变可执行逻辑。

启用 IP 来源须提供已审核的初始 CIDR 和实际观测时间，自动更新格式也使用该基准启动校验。变更来源地址时需重新填写基准；同一身份同时只绑定一个启用 IP 来源。维护者可先停用旧来源，再发布新的绑定。人工来源不会自动延长证据有效期。

## DNS、签名和可信边缘证据

Googlebot 与 Applebot 可在合法源 IP 尚可用的采集阶段执行官方反向 DNS 后正向 DNS 校验。后缀使用域名边界，正向结果必须包含原 IP；批次总量、并发、域名数和时间均有上限。预算耗尽、事件过旧、超时或缺失输入保持未核验。持久证据仅记录方法、时间和最小摘要，不保存原 IP、完整 UA 或 PTR 名称。

ChatGPT Agent 使用独立签名身份。现有授权 Cloudflare 来源在字段探测确认可用后，可使用官方精确检测 ID `129220581` 建立边缘证据；同时校验有效连接、Zone、采集任务和网站配置。泛化 BotScore、通用 bot 标签、普通文件导入自报 Detection ID 和公开 payload 均不建立可信身份。网站停用及分类覆盖同时适用于签名身份，完整配置变更会阻止旧版本在途批次提交。

精确边缘身份与 UA 身份不一致时，规范身份保持歧义，不纳入确定厂商或已核验身份统计；可信边缘证明作为独立证据保留。相同身份的多种证明不会增加请求数量。

目录记录 ChatGPT Agent 与 Exa 的官方签名资料和密钥目录。本版本未实现通用 RFC 9421 签名验证器，仅有 Signature-Agent 或 Signature 字段不能标记签名验证成功。`verified_dns` 与 `verified_edge` 分别显示，IP 范围筛选只包含范围核验，全部身份核验筛选可包含三种已接入结果。

浏览器 PV / UV 仅包含符合来源与质量政策的浏览器事件；授权服务器事件和服务器日志独立统计。网站关闭爬虫识别不会关闭全局浏览器自动化排除。浏览器 IP 过滤仍使用独立的既有可信来源名单，后台新增范围不会扩大该名单。
