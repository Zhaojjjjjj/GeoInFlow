# 流量证据与统计口径

猎看把身份依据、响应结果、采集上下文和业务结果分别展示。新增观察记录保持现有浏览器质量策略；历史缺失继续显示为未知。

## 身份与响应

蜘蛛分析默认使用全部已识别声明，可切换到官方地址范围匹配。主表、趋势、前期比较、目录响应、日志明细与 CSV 使用同一个身份条件。范围外参考保留未核验和未匹配请求，并提供显式切换入口。

从网站入口打开身份、性能和业务效果时，默认展示全部蜘蛛；从具体蜘蛛入口打开时保留其身份，包括同名自定义蜘蛛。三个证据页共享显式蜘蛛选择，详情页保留独立选择。改变身份范围会退出旧身份明细并返回对应矩阵；范围外参考的显式跳转会切换到全部声明并打开所选明细。

矩阵的三种身份互斥：官方范围匹配、官方范围未匹配、未核验。响应列分别为 1xx、2xx、3xx（排除 304）、304、拒绝类（401/403/429/451）、其他 4xx、5xx。GET 2xx 单独计数；HEAD、无正文的 204/205、分段响应 206 保留各自含义。目录 GET 2xx 响应覆盖不证明收录或引用。

Amazonbot、Amzn-SearchBot、Amzn-User 使用各自的官方清单。网页内嵌 JSON 只按固定地址、结构及公开 CIDR 规则解析。发布与观察时间分别保存。来源失效沿用已有过期机制。

## 采集对账

对账要求选择一个日志来源、主机、窗口和页面目录。时间区间统一为左闭右开。原始编码路径保持原样，浏览器路径仅进行一次解码；多条编码路径合并到同一浏览器路径时标明歧义，停止计算差额。

候选人类请求是所选目录中的 GET 2xx 未识别请求。逐条主机依据、来源配置及连续性、采样比例、浏览器输入或路径对应不足时，差额显示不可比较。服务器声明的主机用于定位来源；真实请求主机用于证明同主机。浏览器缺输入、历史主机未知和观测零值有独立状态。内容类型覆盖与已确认 HTML 子集独立展示，缺字段不会被推断为 HTML。

缓存、SPA 路由、脚本拦截、预取和日志缺口都可能产生差额。对账结果用于定位采集差异。

## 浏览器观察

公共浏览 PV 在同一个事务内提交事件、属性、收入、质量、可选 UUID 回执及观察证据。重复 UUID 保留首次观察，冲突或任一写入失败会回滚整个事务。

保存的有限标签包括 Accept 类型、Accept-Language 是否存在及 Sec-Fetch-Site/Mode/Dest 类别。观察表不保存完整请求头、原始 IP 或完整 UA，公开载荷不能覆盖可信上下文。Accept 标签允许重叠，分类 UV 不可相加。

默认总体为原始公共 PV，可切换为当前质量策略纳入的公共 PV。按接收时间显示最近 7 个完整自然日，时区和窗口在分页及导出时保持一致。缺整行、缺字段、字段无效、混合版本和接收时间未知分别说明。既有行为观察的交叉以事件及会话去重，不改变质量策略。

观察 API 的 `meta.observationIdentity` 使用 `received-browser-identity-v1` 版本，按 `received_at` 的左闭右开窗口独立核验所选总体。`population` 分别为 `raw_public_pv` 和 `eligible_public_pv`；原始总体保留被质量策略排除的访问。`totalPV` 记录该总体的 PV，`qualifiedPV` 和 `qualifiedVisitors` 记录具备可靠身份依据的子集，`coverage` 为两者的 PV 比例，空总体为 null。`status` 区分 `complete`、`partial`、`unavailable` 和 `empty`，同时返回实际窗口、时区及身份版本集合。任一 PV 缺少身份依据时，行 UV、总 UV、会话数和交叉观察 UV 返回 null；PV、请求特征及观察覆盖继续保留。该元数据参与快照摘要并随 CSV 导出，事件时间统计的身份覆盖不能证明接收时间总体完整。

逻辑读取限定最近 30×24 小时。worker 每个维护周期分批删除过期观察，更新清理水位。事件删除级联清理；重置清除观察及水位。清理入口：

```sh
node dist/liekan-worker.mjs --prune-traffic-observations-once
```

此入口只清理观察并退出。回退后保留新版产物执行一次；回退超过 24 小时时，由维护者每日执行，失败需处理。配置从受保护运行环境注入。

## 边缘字段与性能

Cloudflare 字段能力由明确配置流程读取。已有日志 Job 保持原配置，可选字段的缺失、无支持、无效和未知分别展示。BotScore 0 或未计算状态不归入低分蜘蛛；评分与评分来源冲突保留为无效。

供应商配置观察保留观察时间和接收时间，仅说明接收时读取到的配置。迟到批次及历史记录缺少事件时点的配置证明时，采样情况保持未知。API 与 CSV 的 `unsampled` 使用 null 表示未知、true 表示已证明未采样、false 表示已证明存在采样；现有自动接入协议不生成事件时点采样证明。

边缘完整响应耗时使用 RFC3339 起止时间的纳秒差；上游响应耗时保留官方含义，包含连接和路由时间。OriginResponseStatus 0 无法归因上游响应。负值、无效时间和超过 600,000 ms 的样本分别处理，其他有效指标继续可用。

字节按边缘响应正文、日志响应字节和未知单位分开。有效零值保留；缺失字节排除于有效样本。合计使用 PostgreSQL numeric 并输出十进制字符串，避免超过 JavaScript 安全整数后丢精度。峰值使用完整 UTC 分钟；不完整首尾分钟单列。峰值 RPS 是峰值分钟的平均值。采样和缺口下的结果只代表已观测数据。

缓存命中占比以已知缓存状态为分母，同时显示全部状态分布与覆盖。耗时使用精确 percentile_cont P50/P95，少于 20 个有效样本有提示。

## 风险处理与上下文

已查看、暂缓 1 小时/24 小时/7 天、恢复待处理和备注独立于技术检测事实。每次操作绑定请求 UUID、工作流版本、事实版本、发生轮次、统计代次和分类版本。同请求重试返回首次结果，变更载荷或并发状态变更返回 409。

恢复后较新的窗口再次触发才增加发生轮次。迟到纠正、旧窗口和缺数据不增加轮次；缺数据过渡之后的新触发仍增加轮次。严重度升级、版本或代次变化、恢复及复发使旧暂缓失效。旧 ignored 状态继续遵循原权限。

详情按来源连续性与身份、响应及公开检查、上下文判断三个步骤排查。策略与检查入口使用已有独立预览和确认流程。人工记录保存实际发生时间、录入时间、作者及作废原因。网站统计重置保留人工记录；默认只关联当前代次，历史入口展示原代次或未知。网站删除清理记录；作者删除保留记录并显示已删除用户。风险工作流和动作随 finding 生命周期清理。

## 平台与落地页

OpenAI、Anthropic、Perplexity、字节的明确来源映射可在可比条件完整时计算每引荐会话对应的观测抓取请求数。Google/Gemini、Microsoft/Copilot、百度/文心分别显示，缺少明确对应时比例保持不可用。

浏览器侧复用现有共享质量总体及会话入口归因。跨窗入口保持一致，转化会话以会话去重，目标事件按匹配事件计数。平台和落地页的目标事件、AI 引荐浏览量及来源证据中的浏览量都依赖入口与后续事件的访问归属；窗口身份为 `partial` 或 `unavailable` 时，这些归因指标返回 null。当前与前期分别使用各自窗口的身份依据。无目标配置、无浏览器输入和主机未知保留 null；零引荐不计算比例。抓取和引荐的单边记录仍显示，二者不能证明因果。

## 一致性、权限与导出

新端点仅供完整登录且有网站权限的私有身份使用，拒绝未完成 2FA、分享身份及 API key。写入沿用 draft 权限；访问控制部署继续需要独立控制权限和确认。

新证据读取复用共享计算槽和事务预算，最多 60 秒。并发同条件查询共享计算，每个消费者单独取消，最后一个消费者离开后取消所属数据库事务。结果缓存短暂保存；缓存命中、查询返回和 CSV 发送前重新核验权限。统计代次、策略或目录基准改变会返回冲突。普通持续采集不触发强版本重试。

对账和业务效果通过 `meta.browserPopulation` 返回整个事件时间窗口的浏览器统计口径，保留既有 `meta.population` 字符串。蜘蛛分析的当前与前期各自返回 `population`。身份不足时，UV、引荐会话、转化会话、关键词跳出与转化会话数，以及依赖会话的归因指标和比例返回 null。全站与事件自身页面的浏览 PV、日志请求、直接匹配目标的事件总量继续计数。结果与元数据在同一事务读取、一起缓存，界面与导出保留空值及不可用原因。

分页每页 20 行。快照由窗口内结果和固定统计基准生成；窗口外采集保留页码，窗口内变化返回第一页。CSV 在提交时建立新的完整快照，记录页面快照、导出快照、读取时间、语言、条件与版本。行数或字节预算超限会明确拒绝，不静默截断。单元格按既有隐私和公式防护规则处理。

主表导出保留页面实际读取的窗口与分页条件，在导出事务中重建原页面进行比较，再生成全部匹配行。`viewComparisonScope=rendered_report` 表示比较当前展示的表格及分页总数；`pageComparisonSnapshot` 是导出时重建页面的摘要，`exportSnapshot` 是全量导出数据的摘要。证据详情使用 `complete_evidence` 比较完整总体。下载提示显示读取时间，页面数据变化时显示“按导出时数据生成”。

端点及输入输出见生成的 OpenAPI：`crawler-analysis/evidence`、`performance`、`outcomes`、`export`，`traffic-quality/reconciliation`、`observations`、`export-evidence`，以及 `crawler-context` 和 `crawler-findings/{findingKey}/workflow`。

## 升级与回退

024–027 为增量迁移。026 的早期轮次触发器由 027 移除，轮次由有完整窗口上下文的 worker 维护；迁移解析器支持历史文件中的带引号函数体。已执行迁移的内容与校验和保持不变。

升级顺序为迁移、新 worker、采集应用、界面。回退保留新增表和可空列，旧版本忽略新证据。先停止新增格式的应用写入，保留新 worker 处理队列，再切回旧 worker。回退风险工作流前运行 `node dist/liekan-worker.mjs --invalidate-crawler-workflow-once`，使活动处理状态失效并保留审计，恢复新版后不复活旧暂缓。禁止删表、清空队列或重置业务数据库完成回退。

软件验收使用隔离数据。真实接入另看观察开始时间、完整自然日样本、边缘字段覆盖和日志连续性；这些状态随实际数据积累更新。
