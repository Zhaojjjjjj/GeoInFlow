# 帮助中心

全局与网站侧栏提供“帮助中心”，地址为 `/liekan/help`。入口位于团队管理之后；网站分析中也可直接进入。帮助页复用完整登录、账户栏和现有导航，独立于网站、团队与统计日期。未完成二次验证的账户继续走账户验证流程。

内容包括快速入门、指标词典、配置指南、全球蜘蛛目录和常见问题。搜索在浏览器内匹配中文名称、简称、运营方、UA 标记和正文；输入上限 256 字符，采用字面多词匹配。文档和蜘蛛条目具有稳定地址，支持刷新和浏览器前后导航：

- `/liekan/help?section=metrics`
- `/liekan/help?article=metric-ai-coverage`
- `/liekan/help?crawler=gptbot`

进入帮助中心的链接清除网站、团队、记录标识、日期、来源筛选和返回地址，只保留帮助页自己的分类与条目标识。无效标识显示可返回的空状态。

## 内容与维护依据

`src/lib/liekan/help` 保存随应用发布的结构化内容。文档由安全的 React 文本节点渲染，无远程脚本或 HTML。阅读无需实时访问外部资料服务。资料使用复核日期；厂商官方、CDN 观察、待复核状态分别展示。

指标定义以 `docs/data-definitions.md` 和本版产品实现为准；接入指南依据 `docs/installation.md`、`docs/automatic-logs.md` 和输入契约维护。帮助资料使用猎看统计的产品名称与实际口径。新增或修改指标时，同步更新词典中的定义、公式、单位、来源、窗口、示例与边界。

首页提供 AI 蜘蛛采集专题入口，包括配置与验证、采集识别原理、日志接收服务配置、数据展示与采集状态四篇文档，关联服务器、Cloudflare、手动导入与排障说明。配置文档的“选择网站并开始接入”引导先进入网站管理，再由用户选择目标网站，打开该网站的数据接入页。帮助页保持全局范围，不自动读取或修改网站接入设置。

目录覆盖主要搜索引擎、AI 平台、研究数据与 SEO 工具，并持续扩充。公开资料无法提供完整、永久有效的全球蜘蛛清单。每条资料保留运营方、用途、官方链接、稳定 UA 标记、可核实的完整 UA 示例、robots token、IP 来源、核验方法、处理建议和复核日期。缺少完整 UA 示例或 IP 数据时显示明确状态。

## 资料与识别能力

条目中的“默认分类”和“默认 IP 核验”由 `BOT_RULES` 与产品范围配置计算。网站自定义分类以该网站的设置为准。收录资料不会修改分类规则，也不会扩充服务器端身份核验。

`config/liekan/bot-ranges.json` 是已有产品默认范围；`src/lib/liekan/help/ip-snapshots.json` 仅保存额外的公开帮助资料。后者不进入日志核验。CIDR 明细显示获取时间、官方发布时间及 IPv4/IPv6 数量。当前快照的时间距离超过 7 天时显示过期提示；实时核验仍采用处理时的证据与请求时间。未随附范围的官方 feed 可通过链接查阅。

Google-Extended、Googlebot-News、Applebot-Extended 按用途控制标记展示，其 UA 分类和独立 IP 核验保持未支持。Meta、Bytespider 的条目保留 Cloudflare 观察来源；PetalBot 保留待复核状态。

维护者每周检查已收录 IP 来源，每月复核厂商文档，在应用发布时更新内容与时间。更新失败时保留已收录资料与原始获取日期；只有取得并核对新的来源后才更新复核时间。资料更改需要重新检查官方范围的适用 crawler，避免将厂商共享范围误认为所有用途均已认证。

## 配置草稿

代码块支持复制与 UTF-8 下载，复制失败时提示手工复制。robots 示例明确标为配置草稿，需要合并站点已有文件并部署到源站。帮助中心不会连接源站或 WAF。保护敏感内容使用认证与访问权限；robots 偏好、搜索索引和限速各按相应官方规则配置。

## 验证

目录契约检查深链接、字面搜索、来源地址、控制标记、实际默认能力和快照边界。组件检查无网站阅读、筛选、缺失资料、返回分类、复制失败与下载清理。`scripts/liekan-help-visual.mjs` 使用隔离浏览器检查真实路由、前后导航、键盘操作、桌面与移动布局，生成忽略提交的验收记录。既有 68 个场景、原始图表与导航的验收继续保留；帮助中心使用独立检查。
