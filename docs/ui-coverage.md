# 页面覆盖与功能范围

Liekan 0.2.2 以 design/reference/geo-stats-v3 的 11 页原型和 design/prototypes/liekan-ui-v1 的 68 个补充场景为 UI 基准。原型 HTML、图表、图标、字段、字体及下拉箭头间距保持冻结，获批的导航与文案采用独立增量基准。补充文件校验和记录在 config/liekan/feature-ui.json。

## 补充场景

| 分组 | 场景数 | 接入内容 |
| --- | --- | --- |
| 网站与接入 | 6 | 网站管理、接入向导、跟踪代码、实际接收验证、网站和录制设置 |
| 身份与安全 | 9 | 登录、SSO、账户、密码、2FA、备份代码、API 密钥、偏好 |
| 目标与漏斗 | 4 | 列表、创建编辑、条件和步骤配置 |
| 访客与事件 | 6 | 实时访客、事件、属性、会话、访问时间线 |
| 筛选与人群 | 7 | 筛选、分群、行为人群、留存和关联访问 |
| 高级分析 | 5 | UTM、归因、拆分、对照与注释 |
| 工作空间与协作 | 16 | 团队、成员、后台、工作台、看板、分享 |
| 扩展能力与状态 | 15 | 链接、像素、性能、收入、热力图、回放、完整导出及错误状态 |
| 合计 | 68 | 对照 src/lib/liekan/contracts/feature-pages.json |

所有场景可通过 /liekan/{sceneId} 访问，网站分析携带 websiteId，详情携带 id。已映射的原有路由默认显示新 UI；添加 legacy=1 可查看保留的兼容界面。登录、SSO 与公共分享采用独立入口。原有 60 个 page.tsx 文件均保留；路由数量包含根入口、动态详情和拦截弹窗。

## 数据与权限

页面使用真实接口与权限。缺少数据、真实零、未配置、未授权和暂未支持分别呈现。API 密钥明文和一次性恢复码仅在对应流程中显示；刷新、关闭和跨账号切换后不再展示。完整登录状态按 90 天期限保存在浏览器中，退出和密码变更后需要重新登录。新统计及完整导出接口要求完整登录，并检查资源权限。

分享每次请求读取主库中的当前状态，停用、删除、密码变化和看板范围收缩立即限制后续请求。固定看板的分享及访问权限按实际来源解析，已有记录无需重新保存。密码保护使用哈希，公共响应仅返回是否有密码；并发元数据编辑与密码更新在同一行锁事务内保存。新建分享采用浅色；已有主题配置保持保存并提供兼容说明。

## 当前边界

- 新 UI 使用简体中文和浅色视觉。其他既有语言、主题与未适配看板组件保留配置，兼容入口继续可用。
- 补充旅程、会话明细、精确滚动到达和完整导出当前支持 PostgreSQL；ClickHouse 请求返回明确的暂未支持提示。原有统计接口保持两后端兼容。
- 预约指标根据已配置且名称明确包含预约语义的目标统计；未配置时保留原型字段并显示状态。访客基于采集访问标识，无跨月身份拼接或跨币种换算。
- 热力图依赖真实页面快照、点击和滚动事件，回放依赖完整 rrweb 快照。未采集时显示接入或空状态。
- 完整导出为请求内即时生成，日期范围上限 3 年、明细上限 100,000 行、处理及下载数据上限 50 MiB。取消停止后续查询和文件传输；已开始的数据库查询结束后检查取消状态。无后台导出队列。

## 维护验收

页面排行、入口与退出页、访问路径、访问记录、爬虫页面、性能与热力图中的页面地址使用当前网站域名补全，并可在新窗口打开。已采集的完整 HTTP/HTTPS 地址优先保留；网站仅配置域名时采用 HTTPS，显式协议和端口继续使用。时间线中的实际主机名与网站域名一致时保留配置端口，其他已观测主机使用其主机名。查询参数、锚点和原始路径编码继续保留。缺失域名、通配域名、域名列表、无效地址及无法区分页面的事件节点保留原文。仅包含页面的访问旅程支持逐步打开；混合事件路径保持原有标识与筛选口径。搜索同时支持原路径和展示的完整地址，CSV 继续保留原路径字段。

2026-10-11 获批的完整地址展示使用增量视觉验收：保留原型指纹、原始截图与像素差异、指标和图表几何检查；随后仅替换隔离浏览器中参照表格的页面文本，检查完整地址带来的列宽变化。每个页面单元格还验证展示地址、打开目标及新窗口属性。原型文件继续冻结。

访问记录与访问旅程详情中的同款表格共用列宽规则：访客、时间、地域、来源、页面数、时长及操作保持单行，完整 URL 允许换行。窄屏继续在表格内横向滚动。

pnpm liekan:verify 检查冻结依赖、生成契约、SDK、类型、回归、原型指纹、核心登记、生产构建和隔离 Docker。候选使用独立端口和数据库副本，验证迁移重复执行、恢复、API 与浏览器布局；正式定版需要完整验收结果。见 [上游更新流程](upstream-upgrade.md)。

## 导航与文案基准

全局管理采用 7 个平铺的一级入口，网站分析保留 7 个模块，账户、系统管理、认证与公开分享保持独立上下文。增量基准见 `config/liekan/navigation-ui.json`，维护规则见 [导航与页面层级](navigation.md)。原型 HTML 及其指纹继续冻结，主体图表、表格字段、面板颜色和圆角仍使用原基准校验。导航视觉验证对获批侧栏、页头与工具条区域单独验收，并校正其带来的主体纵向位置变化。


来源关键词使用独立增量基准 `config/liekan/keyword-ui.json` 与 `design/reference/source-keywords-v1/keywords.html`。原 GEO 页面与既有功能页的指纹继续独立校验。关键词验收覆盖桌面和移动宽度、长文本换行、表格横向滚动、筛选、跨页排序、完整导出与手动刷新。
